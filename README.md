# Appointment Calendar Website

A fully interactive appointment booking web application built with HTML, CSS, and JavaScript.  
This project allows users to view a calendar, book, view, and delete appointments, and store data locally using the browser’s localStorage.

---

## Features

- **Interactive Calendar**  
  Navigate through months with previous and next buttons, with the current day highlighted automatically.

- **Appointment Booking**  
  Add appointments by entering a title, selecting a time, and providing a reason.  
  Prevents double-booking the same time slot and visually marks appointment days on the calendar.

- **Appointment Management**  
  View all appointments for the selected day and delete them directly from the interface.  
  Automatically saves all data using localStorage for persistence.

- **Responsive Design**  
  Clean, modern interface built with custom CSS and Font Awesome icons.  
  Works smoothly across various screen sizes.

---

## Technologies Used

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure and layout of the calendar and appointment interface |
| **CSS3** | Styling, responsive layout, and hover effects |
| **JavaScript (Vanilla)** | Core functionality, DOM manipulation, and data handling |
| **Font Awesome** | Icons for buttons and visual elements |
| **LocalStorage** | Persistent storage for appointments |

---

## How It Works

1. Open `index.html` in your browser.  
2. Use the navigation arrows to move between months.  
3. Click on a date to view or add appointments.  
4. Use the plus (+) button to open the booking form.  
5. Enter appointment details and click **Book Appointment**.  
6. View or delete appointments directly from the appointment panel.  

All appointments are stored locally and remain after refreshing the page.
